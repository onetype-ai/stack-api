# tables/

One definition for SQLite and Postgres, from `@onetype/stack-api-kit/tables`,
never `sqliteTable` or `pgTable`. The SQL name carries the plugin, so two
plugins may each own a table of one name. Columns are `camelCase` in code,
`snake_case` in the database. Every index starts with the scope column,
because `ctx.scoped` is in every read.

```ts
import { column, index, table } from "@onetype/stack-api-kit/tables";

export const items = table("items_items", {
    id: column.id().primaryKey(),

    tenantId: column.text("tenant_id").notNull(),

    title: column.text("title").notNull(),
    isArchived: column.boolean("is_archived").notNull().default(false),
    createdAt: column.timeMs("created_at").notNull(),
}, (table) => [
    index("items_items_by_created").on(table.tenantId, table.createdAt),
]);
```

A time is `column.timeMs`, JSON `column.json<Shape>()`. Every query is
awaited: `.get()`, `.all()` and `.run()` answer on SQLite alone, and verify
names each `[dialect]`.

A `uniqueIndex` rejects a duplicate: insert with `onConflictDoNothing` and
check the result, since no row means the index refused it.
