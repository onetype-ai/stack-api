# tables/

The SQL name carries the plugin, so two plugins may each own a table of one
name. Columns are `camelCase` in code, `snake_case` in the database. Every
index starts with the scope column, because `ctx.scoped` is in every read.

```ts
import { index, integer, sqliteTable, text } from "drizzle-orm/sqlite-core";

export const items = sqliteTable("items_items", {
    id: text("id").primaryKey(),

    tenantId: text("tenant_id").notNull(),

    title: text("title").notNull(),
    isArchived: integer("is_archived", { mode: "boolean" }).notNull().default(false),
    createdAt: integer("created_at").notNull(),
}, (table) => [
    index("items_items_by_created").on(table.tenantId, table.createdAt),
]);
```

A `uniqueIndex` rejects a duplicate: insert with `onConflictDoNothing` and
check the result, since no row means the index refused it.
