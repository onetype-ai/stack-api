# plugin.ts

The contract: everything crossing the boundary, named here or absent; the
kernel refuses to start on a missing declaration. Required: `version`,
`describe`. Its three types are `ctx.config`, `ctx.services`, `ctx.db`.

```ts
export default definePlugin<typeof ItemsConfig.schema, ItemsServices, ItemsDb>("items", {
    version: "1.0.0",
    describe: "Items a tenant keeps, each with a title.",

    dependsOn: ["other"],
    config: ItemsConfig.schema,

    tables: { items },
    migrations: "./src/plugins/items/migrations",
    scope: { describe: "Every item belongs to one tenant.", claim: "tenant", tables: { items: "tenantId" } },

    permissions: { "items.read": { describe: "Read items." } },

    services: (ctx) => ({ items: new Items(ctx) }),
    routes: [...itemsRoutes],
    allowedHosts: ["https://example.com"],

    emits: { "items.item.created": { describe, schema: ItemCreated.schema } },
    channels: { "items.item": { describe, schema, reach: "scope" } },
    hooks: { "items.item.before-remove": { describe, schema } },
    listens: { "other.thing.happened": listener(schema, { describe, handle }) },
    participates: { "other.thing.before-remove": participant(schema, { describe, handle }) },
    commands: { "items.archive": command({ describe, schema, run }) },
    watchesWork: true,

    setup: (ctx) =>
    {
        ctx.log.info("ready");
    },
    teardown: (ctx) =>
    {
        ctx.log.info("stopped");
    },
});
```

`watchesWork` grants `ctx.work`, the health of jobs and the outbox. The
plugin that knows who is calling also declares:

```ts
    identifies: (ctx, request) => ({ id: "<caller id>", claims: { tenant: "<tenant id>" } }),
    grants: (ctx, identity) => ["items.read"],
    grantsSupported: ["items.read", "items.write"],
```
