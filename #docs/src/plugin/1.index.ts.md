# index.ts

The public API: the only file another plugin may import, and only when it
names this one in `dependsOn`. Everything else in the folder is private.
Design it, with `usage.md`, before anything inside.

It hands out what a caller needs now (a function over a service) and the
schemas of what this plugin emits, so a listener parses what was sent.

```ts
import type { Context } from "@onetype/stack-api-kit";

import type { Item } from "./schemas/Item";
import type { ItemsServices } from "./types/ItemsServices";

const services = (ctx: Context) => ctx.use<ItemsServices>("items").items;

export const Items = {
    get: (ctx: Context, id: string): Promise<Item> =>
    {
        return services(ctx).get(id);
    },
};

export { ItemCreated } from "./schemas/ItemCreated";
export type { Item } from "./schemas/Item";
```

Another plugin reaches it as `import { Items } from "@plugins/items"`.
