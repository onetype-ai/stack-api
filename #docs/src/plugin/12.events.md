# Events

An event says something happened, to whoever listens; nobody answers. The
emitter declares it in `emits` and exports its schema from `index.ts`. Emit
inside `tx`: it is sent after the commit, never for rolled-back work.

A listener runs for nobody, so the payload carries the tenant, and
`forScope` acts in it. Delivery is at least once: handle a repeat.

`activity/plugin.ts`

```ts
import { ItemCreated } from "@plugins/items";

const listener = defineListener<ActivityContext>();

export default definePlugin<never, ActivityServices, ActivityDb>("activity", {
    dependsOn: ["items"],

    listens: {
        "items.item.created": listener(ItemCreated.schema, {
            describe: "Records that an item was created.",
            handle: async (payload, ctx) =>
            {
                await ctx.forScope(payload.tenantId).services.activity.record(payload.id);
            },
        }),
    },
});
```

`activity/services/activity.ts`: a unique index on `(tenant_id, item_id)`
makes the repeat record nothing.

```ts
await this.#ctx.write(() => this.#ctx.db.insert(entries).values({ id: crypto.randomUUID(), itemId, at: this.#ctx.now(), ...this.#ctx.stamped("entries") } as Row).onConflictDoNothing());
```
