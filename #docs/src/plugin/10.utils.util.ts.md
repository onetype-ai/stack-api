# utils/

Pure code with no domain: it takes values and answers values. `src/utils/`
is reachable by every plugin; a plugin's own `utils/` by that plugin alone.
Importing a plugin or the kit is a lint error: needing `ctx` makes it a
service.

`Slug.ts` exports one object of that name, its methods the members:

```ts
export const Slug = {
    of: (title: string): string =>
    {
        return title.trim().toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/^-|-$/g, "");
    },
};
```

Add one when two places need it, not before.
