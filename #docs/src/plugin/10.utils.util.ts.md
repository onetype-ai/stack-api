# utils/

Pure code with no domain: it takes values and answers values. `src/utils/`
is reachable by every plugin; a plugin's own `utils/` by that plugin alone.
Importing a plugin or the kit is a lint error: needing `ctx` makes it a
service.

`<Type>.ts` exports one object of that name, its methods the members, as
`Settings` and `Plugins` in `src/kernel/` are written.

```ts
export const <Type> = {
    <member>: (raw: string): string =>
    {
        return <raw, made regular>;
    },
};
```
