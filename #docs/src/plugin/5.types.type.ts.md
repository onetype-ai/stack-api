# types/

Shapes describing code alone: nothing here crosses the boundary or parses.
Three every plugin has; the rest is whatever the code needs.

`ItemsDb.ts`

```ts
import type { PortableDb } from "@onetype/stack-api-kit/tables";

import type { items } from "../tables/items";

export type ItemsDb = PortableDb<{ items: typeof items }>;
```

`ItemsServices.ts`

```ts
import type { Items } from "../services/items";

export type ItemsServices = {
    items: Items;
};
```

`Context.ts`, the `ctx` every service, route and listener is written against:

```ts
import type { Context } from "@onetype/stack-api-kit";

import type { ItemsConfig } from "../schemas/ItemsConfig";
import type { ItemsDb } from "./ItemsDb";
import type { ItemsServices } from "./ItemsServices";

export type ItemsContext = Context<ItemsConfig, ItemsServices, ItemsDb>;
```
