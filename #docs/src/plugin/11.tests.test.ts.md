# tests/

`items.test.ts`, flat, one subject a file. Test the outermost thing: the
route, the public API, the listener; never the inside. Every refusal in
`usage.md` has a test. The database is real, in memory, migrated.

Name only the plugin under test: what it depends on comes from
`src/plugins`, configured by `boot.env`. `schedule: true` and `now` reach a
job; `api.drain()` runs it.

Where rows belong to a tenant, write in two, act as one, see nothing of the
other's.

```ts
const tenantA = createIdentity(["items.read", "items.write"], "person-a", { tenant: "a" });
const tenantB = createIdentity(["items.read", "items.write"], "person-b", { tenant: "b" });

let api: TestKernel;

beforeEach(async () =>
{
    api = await startTestKernel({ plugins: [items], schedule: true });
});

afterEach(async () =>
{
    await api.stop();
});

test("two tenants never see each other's items, in a list or by id", async () =>
{
    await api.kernel.handle({ method: "POST", path: "/items", input: { title: "Kept by A" }, identity: tenantA });
    const created = await api.kernel.handle({ method: "POST", path: "/items", input: { title: "Kept by B" }, identity: tenantB });
    const idOfB = (created.body as { id: string }).id;

    const listedByA = await api.kernel.handle({ method: "GET", path: "/items", input: {}, identity: tenantA });
    const readByA = await api.kernel.handle({ method: "GET", path: `/items/${idOfB}`, input: {}, identity: tenantA });

    expect(listedByA.body).toEqual({ items: [expect.objectContaining({ title: "Kept by A" })] });
    expect(readByA.status).toBe(404);
});
```

cause, then restore. A test that has never failed proves nothing.
