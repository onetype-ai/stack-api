# usage.md

What another developer reads before building against this plugin: under
1800 characters, written before the code.

```md
# items

## Description

Items a tenant keeps, each with a title. `POST /items` creates one and emits
`items.item.created`. Another plugin reads one with `Items.get(ctx, id)`.

## Refusals

- 400 `BAD_TITLE`: the title is empty or only spaces.
- 404 `NOT_FOUND`: no item by that id in the caller's tenant.

## Does not

- Decide who the caller is or which tenant they act for.
```

Every refusal listed has a test that triggers it.
