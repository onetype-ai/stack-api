# Jobs

Work that runs later is a command, declared in `commands` and asked for with
`ctx.commands.later(name, input, inSeconds)`. Asked inside `tx`, it is saved
by that transaction and rolls back with it. It runs for nobody: the tenant
travels in the input. One that throws is tried again, so it must be safe to
repeat.

`items/plugin.ts`

```ts
const command = defineCommand<ItemsContext>();

    commands: {
        "items.archive": command({
            describe: "Archives one item once it is old enough.",
            schema: z.object({ tenantId: z.string(), id: z.uuid() }),
            run: async (input, ctx) =>
            {
                await ctx.forScope(input.tenantId).services.items.archive(input.id);
            },
        }),
    },
```

`services/items.ts`, in `create`:

```ts
inside.commands.later("items.archive", { tenantId: row.tenantId, id: row.id }, inside.config.archiveAfterDays * DAY_SECONDS);
```

Only a process started with `SCHEDULE=true` runs what is due.
